Distros & Guide

A short comparison of popular distros for customizing your desktop. If you are new to Linux, start with an easier distro; if you want full control over every part of the system, try a more advanced one.

Distro comparison

Which one should you choose?

  • Ubuntu is the easiest start because almost everything works out of the box.
  • Fedora gives you recent software with a friendly installer.
  • Arch Linux takes more time to set up, but you build the system exactly the way you like it, which is why many ricers use it.

Installation Guide

Watch the video

Full text description of the video

The video starts in a studio. The narrator, Derek from DistroTube, sits in front of a microphone and talks to the camera. A caption at the bottom says “Arch Linux Installation Guide (Estimated Time: 15 Minutes)”. He says that Arch Linux is one of the most popular Linux distributions and also one of the quickest and easiest to install. He explains the plan: a traditional installation from the command line with the base packages, the Linux kernel and the niri window manager, which is a Wayland compositor. The drive will be partitioned, Btrfs will be the file system and zram will be used for swap. He says the whole process takes 15 minutes or less, so you can set a timer.

The picture changes to a screen recording, and the narrator is now visible in a small webcam picture in the bottom right corner. He opens the website archlinux.org (“A simple, lightweight distribution”) and clicks on the Download page. He explains that the ISO image can be downloaded with a torrent or directly from one of several mirrors, and says that he has already downloaded it.

He explains that he will install Arch Linux in a virtual machine, but the process is very similar on a physical computer. On his desktop, which has a wallpaper of green hills under an orange sky, he opens the program virt-manager from an application menu and creates a new virtual machine. In the wizard he selects the Arch Linux ISO from his Downloads folder, and the program recognises it as Arch Linux. He gives the machine about 6 GB of RAM, 2 of his 24 CPU cores and 20 GB of disk space, names it “Arch-Linux-install” and clicks Finish.

The virtual machine starts, he makes the window full screen, and the white text of the Arch Linux installer appears on a black screen. The clip ends as he says: “And now we come to the command prompt.”

Quick Steps

  1. Download the ISO. Get the image from the official website of your distro.
  2. Make a bootable USB. Write the ISO to a USB drive.
  3. Install the system. Boot from the USB drive and follow the installer.
  4. Pick a window manager. Choose a desktop environment or a tiling window manager.
  5. Add themes and dotfiles. Install a theme, an icon pack and your configuration files.
