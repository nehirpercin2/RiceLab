Distros & Guide

A short comparison of popular distros for customizing your desktop. If you are new to Linux, start with an easier distro; if you want full control over every part of the system, try a more advanced one.

Which one should you choose?

  • Ubuntu is the easiest start because almost everything works out of the box.
  • Fedora gives you recent software with a friendly installer.
  • Arch Linux takes more time to set up, but you build the system exactly the way you like it, which is why many ricers use it.

Installation Guide

Watch the video

Full text description of the video

The video starts with a title card: “Installation guide”. Then the steps follow one after the other, each with a title card and a short explanation.

First the narrator shows the official website of the chosen distro and downloads the ISO image. Next, the ISO file is written to a USB drive with a flashing tool. After that, the computer is restarted from the USB drive and the graphical installer is shown: the language, the keyboard layout, the disk and the user name are selected, then the installation runs until it finishes. In the fourth part a window manager is installed and selected on the login screen. In the last part a theme, an icon pack, a font and the configuration files (dotfiles) are applied, and the desktop changes its look. The video ends with the finished desktop.

Quick Steps

  1. Download the ISO. Get the image from the official website of your distro.
  2. Make a bootable USB. Write the ISO to a USB drive.
  3. Install the system. Boot from the USB drive and follow the installer.
  4. Pick a window manager. Choose a desktop environment or a tiling window manager.
  5. Add themes and dotfiles. Install a theme, an icon pack and your configuration files.
